# Security Policy

## Supported versions

Security fixes are applied to the latest release. Please upgrade before
reporting an issue.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Adamkadaban/termshot/security/advisories/new).
Please do not open a public issue.

Include the affected version and platform, the potential impact, and a minimal
reproducer when possible. Reports will be acknowledged as soon as practical,
and disclosure will be coordinated with the reporter.

Termshot's redaction is pattern-based and cannot recognize every possible
secret format. A failure to mask a documented built-in pattern, or exposure of
unredacted data after redaction succeeds, should be reported privately.
